## Why

Afallon Compendium is a wiki-like reference generated from game files, but its page metadata never says "wiki." People searching for an Afallon wiki should be able to recognize this reference in search results without mistaking it for a hand-edited site.

## What Changes

- Use Afallon Wiki in browser and sharing titles for reference pages while retaining Afallon Compendium as the site's name.
- Identify Afallon Wiki as an alternate WebSite name and describe the generated reference accurately in home and About copy.
- Add natural wiki language to relevant metadata descriptions without replacing useful page facts.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `compendium-reference`: Define discoverable page titles, descriptions, and structured site identity as part of published-page SEO.

## Impact

The SvelteKit home, list, entity, map, About, Coverage, and 404 routes, shared SEO metadata, deployment title checks, and published static HTML change. No URL, underlying game data, or editorial workflow changes.
