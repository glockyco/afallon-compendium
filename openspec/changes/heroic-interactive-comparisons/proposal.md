## Why

The Heroic Tier page describes strength and rewards in reference tables but does not let readers compare a real eligible encounter or equipment piece with its Normal form. A player needs an honest comparison that keeps conditional events conditional and derives numbers from the published build.

## What Changes

- Add a selectable published outdoor creature, remembered gear score, and Normal versus conditional Empowered comparison for strength, kill experience, and possible rewards.
- Add a Normal versus Heroic preview of published eligible creature-drop equipment, using the existing item tooltip and comparison table presentation.
- Keep current strength and Essence reference tables, and distinguish places where the tier pauses.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `mechanics-pages`: Add interactive creature and item comparisons to the Heroic Tier page without weakening its existing reference material.

## Impact

Site Heroic Tier page, shared item comparison UI, browser-local score preference, and focused calculations/tests. No change to published game facts or game data.
